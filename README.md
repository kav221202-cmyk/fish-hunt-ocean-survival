
# Fish Hunt: Ocean Survival

A browser-based 2D survival game developed for CIS045-3
Distributed Service Architectures.

## Project goals

The game will demonstrate:

1. Low coupling and high cohesion.
2. Event-driven programming.
3. Interoperability using the required Fish Game API.
4. Virtual identity through authentication and session management.

## Technology

- HTML5
- CSS
- JavaScript ES modules
- HTML5 Canvas (planned for gameplay)
- Fish Game API (integration under investigation)

## Current status

Phase 1: Project foundation and API investigation.

The initial interface and click-event handler are implemented.
Core gameplay and API integration are not yet implemented.

## Run locally

Serve the project folder using a local HTTP server.

For example:

    py -m http.server 5500

Then visit:

    http://localhost:5500
